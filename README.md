 📊 Project Overview

This project analyzes the academic performance of 7,000 students using Power BI.

The dashboard provides insights into student scores and explores relationships between academic performance and factors such as gender, parental education, study time, sleep duration, test preparation, school type, and internet access.

🎯 Objectives

- Analyze overall student academic performance
- Compare Math, Reading, and Writing scores
- Analyze performance by gender
- Analyze the impact of parental education
- Analyze study time and academic performance
- Analyze sleep duration and academic performance
- Compare students based on test preparation
- Identify high and low performing student groups

 🛠️ Tools & Technologies

- Power BI
- Power Query
- DAX
- CSV
- Data Visualization

 📂 Dataset

The dataset contains 7,000 student records and includes:

- Student ID
- Gender
- Race/Ethnicity
- Parental Education
- Lunch Type
- Test Preparation
- Study Time
- Sleep Duration
- Math Score
- Reading Score
- Writing Score
- School Type
- Internet Access

 🔄 Data Cleaning

Data cleaning and transformation were performed using Power Query.

Steps included:

- Removing/handling missing values
- Checking data types
- Cleaning categorical fields
- Validating numerical fields
- Creating calculated columns

 📐 DAX Calculations

Created measures and calculated columns for:

- Total Students
- Average Math Score
- Average Reading Score
- Average Writing Score
- Overall Average Score
- Pass Percentage
- Passed Students
- Failed Students
- Performance Category
- Student Ranking
